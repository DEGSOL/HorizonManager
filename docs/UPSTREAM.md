# Исследование оригинального Horizon

Проверенная ревизия `12d5fbde4d9e0776a48618ea65d16fe6d1e1b606` от 15 ноября 2026 года. В `pyproject.toml` указана версия `0.1.0` и Python ≥ 3.11. Полный commit хранится в `bootstrap/horizon.commit`, установщик сверяет Git HEAD и устанавливает зависимости из `uv.lock`. Исходники Horizon остаются без изменений. [Официальный репозиторий](https://github.com/Thysrael/Horizon) · [зафиксированная ревизия](https://github.com/Thysrael/Horizon/tree/12d5fbde4d9e0776a48618ea65d16fe6d1e1b606)

## Установка и модель выполнения

- README, `pyproject.toml`, Dockerfile, Compose, пример конфигурации и `.env.example` описывают Python-проект с одноразовым CLI `horizon`. Штатный Dockerfile устанавливает Horizon через uv. Compose монтирует `data` и `.env`, запускает сбор и завершается, `restart: "no"`. 
- `horizon-wizard` — интерактивный помощник установки источников и AI. Он записывает конфигурацию и параметры в файлы. В Manager тот же формат применяется визуальными формами и нативными валидаторами Horizon.
- `horizon-mcp` работает по stdio. Инструменты `hz_validate_config`, `hz_fetch_items`, `hz_score_items`, `hz_filter_items`, `hz_enrich_items`, `hz_generate_summary` и `hz_run_pipeline` используют `HorizonPipelineService`. Это точка интеграции агента. Артефакты `meta.json`, `raw_items.json`, `scored_items.json`, `filtered_items.json`, `enriched_items.json` и `summary-<lang>.md` сохраняются для каждого запуска. [Документация MCP](https://github.com/Thysrael/Horizon/blob/main/src/mcp/README.md)
- `scripts/daily-run.sh` ориентирован на cron и обновляет checkout с main перед публикацией GitHub Pages. В Manager расписанием и состоянием заданий управляет агент. Этот скрипт не входит в путь установки.

## Источники и извлечение текста

- Нативные модели в `src/models.py` и скраперы в `src/scrapers/` подтверждают RSS/Atom, Reddit, Telegram, GitHub, Hacker News, OSS Insight, GDELT, Google News, X/Twitter и OpenBB. Агент выдаёт JSON Schema нативной модели; Android по ней отображает графические поля.
- Telegram читает общедоступную HTML-ленту публичного канала. GitHub применяет типы событий пользователя и релизов репозитория, необязательный `GITHUB_TOKEN` повышает лимиты. Google News и GDELT используют отдельные поисковые параметры. RSS умеет извлекать полный текст через Trafilatura и внешние сервисы.
- X поддерживает в upstream Apify и Playwright. В этой установке Manager предусматривает Apify и переменную для его токена. Playwright требует дополнительный браузерный runtime и собственные cookie. OpenBB требует extra `openbb` и, в зависимости от источника, свои учётные данные. Стандартная установка Manager этот extra не ставит. [Источники](https://github.com/Thysrael/Horizon/blob/main/docs/scrapers.md) · [Экстракторы](https://github.com/Thysrael/Horizon/blob/main/docs/extractors.md)
- Дизайн HorizonHub в `docs/horizon-hub-design.md` описывает идею отдельного каталога. Исследованная ревизия не даёт готового HTTP API этого каталога. Manager не зависит от HorizonHub.

## AI, профили и результат

- upstream `AIProvider` содержит `openai`, `anthropic`, `gemini`, `azure`, `ali`, `doubao`, `minimax`, `deepseek`, `ollama`, `openai-chatgpt`. OpenAI-compatible — это `openai` с собственным `base_url`. Цепочка задаётся через `provider_chain`; поля throttling и concurrency происходят из upstream. Manager не подставляет названия моделей. [Конфигурация Horizon](https://github.com/Thysrael/Horizon/blob/main/docs/configuration.md)
- Подписочный `openai-chatgpt` использует подтверждение plan usage и браузерный loopback callback в Hovq. Приложение передаёт одноразовый ответ через защищённое подключение к агенту. Horizon проверяет OAuth, а VPS хранит и обновляет сессию. Для проверки используется реальный запрос к сохранённой модели. [Документация upstream](https://github.com/Thysrael/Horizon/blob/main/docs/chatgpt.md) · [процедура для VPS](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms)
- Профиль содержит JSON-описание и Markdown-промпты сопоставления, оценки и обогащения. Вход `profile` допускает конкретный ID, `auto` и список кандидатов. Встроены `tech-news`, `tech-blog`, `finance-news`, `ai-creator`. Настройки порога, дедупликации, размера текста, блоков и инструментов передаются upstream. Из инструментов на этой ревизии есть `web_search` и `history_search`. [Профили](https://github.com/Thysrael/Horizon/blob/main/docs/profiles.md) · [Оценка](https://github.com/Thysrael/Horizon/blob/main/docs/scoring.md)
- Оценка, дедупликация, отбор по квотам и обогащение используют оригинальный код. Manager запрашивает английский, упрощённый китайский и русский через языковые теги Horizon. Manager дополняет шаблон Markdown локализованными заголовками и может перевести архивный выпуск из сохранённых материалов.
- Email и Webhook используют классы upstream. Reminders, push, работающий backend, офлайн-кэш Android, управление состоянием, экспорт/восстановление и журнал операций — функции Manager. Интерактивная привязка WeChat, публикация на Pages и закрытые сценарии авторизации пока не интегрированы. Журнал Manager показывает категории исключений и события этапов. Это обезличенный диагностический формат, пригодный для экспорта.
