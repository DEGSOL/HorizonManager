# MRizon 0.3.0 — feature map from 0.2.0

Baseline Git tree 5f7c4f6667662f939767c1069cd4cf935175bb59. Compose, Room, Android Keystore, WorkManager/UnifiedPush and authenticated agent v1 over pinned SSH or verified HTTPS remain the integration boundaries.

* Feed and archived issue share NewsScreen, ArticleDialog, Markdown and ArticleFlag. Preserve search, scope, category/profile, ordering, original link, clipboard/share, local marks, translations, full Markdown, manual archive and separate sync/run actions. Archive retains time-window partitioning, month filter, cache and pagination.
* Server group owns VPS list, SSH credential edit, host verification, compatibility probe, resumable installation, agent status, generation, cancellation and update actions. Maintenance owns agent checks/restart, upstream version, diagnostics, backup/restore, imports/exports, revision rollback and journal. Source history and local/remote event filters stay in Journal.
* News group owns all schema-driven source integrations, the Telegram editor, digest rules, delivery/scheduling and illustration controls. AI owns provider credentials, router catalog, validation, default and source-specific processing, prompt and output definitions. Interface owns all pre-existing theme IDs, notification/UnifiedPush settings, reading preferences and local counts. Both entry points to secrets use their own actual path.
* Preserve Server/Vault, CachedArchive, CachedDigest, LocalEvent, ArticleFlag and all persistence keys. Server configuration revisions, ProfileDocument IDs, credentials, run artifacts, schedules, push registrations and operations keep their original formats.
* Baseline defects: parent guessed by leaf name; settings route could supersede SSH editing; bottom nav occupied its own opaque layout with additional system padding; news title ellipsized after three lines; partial issues needed manual pagination; digest state used last agent contact as proof of sync; feed API omitted upstream media.

## Проверка выпуска

- Композиции из release-варианта приложения запущены в Robolectric с нативным рендерером Android API 35, русской локалью и экраном 412 × 860 dp. Семь PNG в приложении к выпуску получены из окна MainActivity на тестовых данных. Фотографии NASA входят только в тестовые ресурсы.
- Сценарий пролистывает все 105 записей, проверяет исчезновение кнопок при свайпе вверх и появление при обратном свайпе, открывает и закрывает бабл и статью, проверяет блокировку навигации и читает сохранённый архивный выпуск через Room. Проверены оба входа в «Секреты», возврат в исходный раздел, профили и серверное управление.
- Транспорт проверен на локальном SSH-сервере с проверкой отпечатка, паролем и зашифрованным приватным ключом. Тест меняет параметр подбора иллюстраций через туннель, читает применённое значение и возвращает его обратно. Серверные тесты покрывают запуск обработки RSS, три языка, авторизацию, расписание, историю, отмену, резервное копирование и восстановление.
- Проверены распознавание Telegram-вложения конкретного поста, RSS-вложения и Open Graph, отказ от непригодных URL и выбор AI из нескольких лицензированных кандидатов. Поиск иллюстраций проверен воспроизводимыми ответами Wikimedia Commons и модели. Реальный платный запрос к модели пользователя не выполнялся.
- Релизный package name — `dev.horizonmanager.mobile`, versionCode 9. У 0.2.0 versionCode 8. Сверены APK-сертификаты обеих версий. Новая версия продолжает использовать существующую базу Room и ключи хранилища Android. Серверный агент обновляется отдельно, его API v1 и ревизия самого Horizon сохранены.
- Физический телефон, фирменные системные жесты One UI, производительность при 120 Гц и работа с пользовательским VPS требуют отдельной проверки на устройстве. На Android 8–11 навигация использует облегчённое полупрозрачное оформление. Размытие фотографий под заголовком работает и на этих версиях.
