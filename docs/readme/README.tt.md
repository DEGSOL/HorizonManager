Hovq — үз VPS серверыңа [Horizon](https://github.com/Thysrael/Horizon) урнаштыру, аны идарә итү һәм яңалыклар дайджестларын уку өчен Android кушымтасы. Horizon серверда язмаларны җыя, кабатланганнарын алып ташлый һәм сайланган ясалма интеллект моделе ярдәмендә аларны бәяли, тәрҗемә итә һәм чыгарылыш әзерли.

[Имзаланган APK-ны йөкләү һәм чыгарылыш язмаларын уку](https://github.com/DEGSOL/HorizonManager/releases/latest)

## Мөмкинлекләр

- RSS, Telegram, Reddit һәм Hacker News чыганаклары, бәяләү профильләре, тышлык рәсемнәре һәм сорау буенча тулыландыру.
- Кулдан, атна көннәре буенча яки билгеләнгән вакыттан башлап тигез араларда эшләтү. Расписание VPS серверында үтәлә.
- Эзләү, сөзгечләр һәм укылмаган язмалар булган тасма, сайланмалар, архив һәм челтәрсез уку өчен йөкләнгән чыгарылышлар.
- Гамәлләр журналы, телефон һәм сервер көйләүләренең шифрланган резерв күчермәләре.

## Урнаштыру һәм беренче чыгарылыш

**Урнаштыру өчен Ubuntu Server 24.04 LTS яки Debian 12 эшләгән һәм SSH аша кереп булган үз VPS серверыгыз җитә.** Hovq аша тоташыгыз һәм урнаштыруны раслагыз. Кушымта Horizon системасын, агентны һәм кирәкле пакетларны үзе урнаштыра.

1. APK-ны Android 8.0 яки яңарак версиягә урнаштырыгыз. Ubuntu Server 24.04 LTS яки Debian 12, systemd, SSH һәм операцион системаның репозиторийларына, GitHub белән PyPI-га керү мөмкинлеге булган VPS әзерләгез. Урнаштыручы архитектураны, кимендә 432 МиБ оператив хәтерне һәм 1,5 ГиБ буш урынны тикшерә. Җыю һәм эшкәртү өчен күбрәк ресурс кирәк булырга мөмкин.
2. Hovq эчендә серверны өстәгез, SSH серсүзен кертегез яки шәхси ачкычны сайлагыз. Ачкычның бармак эзен провайдер панеле аша тикшерегез. SSH аша VPS эчендәге `127.0.0.1:18777` адресына юнәлтү рөхсәт ителергә тиеш. Урнаштыруны раслагыз, кирәк булса sudo серсүзен кертегез. Элек урнаштырылган агентка да тоташырга була.
3. Ясалма интеллект көйләүләрендә провайдерны, модельне һәм API ачкычын күрсәтегез. OpenRouter һәм UnoRouter модельләре каталогын кушымтада йөкләргә була. Чыганак өстәгез, эшкәртү профилен сайлагыз һәм җыюны башлап җибәрегез.
4. Чыгарылышны тасмада ачыгыз. Расписаниене яңалыклар көйләүләрендә, дайджест телен ясалма интеллект көйләүләрендә сайлагыз. Интерфейс һәм дайджестлар югарыда күрсәтелгән барлык телләрне хуплый.

## Белдерүләр һәм яңарту

**Көйләүләр → Интерфейс → Белдерүләр** бүлегендә яңа дайджест белдерүләрен кабызыгыз һәм Android-та рөхсәт бирегез. Hovq VPS серверына SSH яки көйләнгән HTTPS аша туры тоташуны саклый. Күзәтү вакытында Android тавышсыз хезмәт белдерүен күрсәтә. Чыгарылыш әзер булгач, аерым белдерү килә. Элемтә өзелсә, Hovq кабат тоташа һәм яңа чыгарылыш бармы икәнен тикшерә.

Бер үк сертификат белән имзаланган Hovq 0.4.5–0.5.8 өстеннән APK урнаштырырга була. 0.4.4 һәм аннан искерәк версияләрне яңадан урнаштыру кирәк. Элек тоташтырылган VPS серверында агентны Hovq аша 0.1.20 версиясенә яңартыгыз. Материалны сорау буенча тулыландырганда да агент төрлечә язылган, әмма бер вакыйга турында хәбәр итүче язмаларны таба. Профильнең тематик кабатлануларны бетерү көйләве гамәлдә кала.

## Чыганак кодыннан җыю

JDK 17 яки 21, Android SDK 36 һәм Build Tools 36.0.0 кирәк. SDK юлын `ANDROID_HOME` яки `android/local.properties` аша күрсәтегез.

```bash
cd android
./gradlew :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
```

Имзаланган APK җыю өчен әйләнә-тирә үзгәрүчәннәрен көйләгез

`HM_RELEASE_KEYSTORE`, `HM_RELEASE_KEY_ALIAS`, `HM_RELEASE_STORE_PASSWORD`, `HM_RELEASE_KEY_PASSWORD`
