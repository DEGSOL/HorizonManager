# Hovq 0.5.6

Hovq — өз VPS серверіңізге [Horizon](https://github.com/Thysrael/Horizon) жүйесін орнатып, басқаруға және жаңалықтар дайджесттерін оқуға арналған Android қолданбасы. Horizon серверде мақалаларды жинайды, қайталанғандарын алып тастайды және таңдалған ЖИ моделінің көмегімен оларды бағалап, аударып, шығарылымды дайындайды.

[Қолтаңбасы бар APK файлын жүктеу және шығарылым жазбаларын оқу](https://github.com/DEGSOL/HorizonManager/releases/latest)

## Мүмкіндіктер

- RSS, Telegram, Reddit және Hacker News дереккөздері, бағалау профильдері, мұқаба суреттері және сұрау бойынша толықтыру.
- Қолмен, апта күндері бойынша немесе белгіленген уақыттан бастап тең аралықтармен іске қосу. Кесте VPS серверінде орындалады.
- Іздеу, сүзгілер мен оқылмаған мақалалары бар таспа, таңдаулылар, мұрағат және офлайн оқуға жүктелген шығарылымдар.
- Операциялар журналы, телефон мен сервер параметрлерінің шифрланған сақтық көшірмелері.

## Орнату және алғашқы шығарылым

**Орнату үшін Ubuntu Server 24.04 LTS немесе Debian 12 жұмыс істейтін, SSH арқылы кіруге болатын өз VPS серверіңіз жеткілікті.** Hovq арқылы қосылып, орнатуды растаңыз. Қолданба Horizon жүйесін, агентін және қажетті тәуелділіктерді өзі орнатады.

1. APK файлын Android 8.0 немесе одан жаңа нұсқаға орнатыңыз. Ubuntu Server 24.04 LTS немесе Debian 12, systemd, SSH және ОЖ репозиторийлеріне, GitHub пен PyPI-ға қолжетімділігі бар VPS дайындаңыз. Орнатушы архитектураны, кемінде 432 МиБ жедел жад пен 1,5 ГиБ бос орынды тексереді. Жинау мен өңдеуге көбірек ресурс қажет болуы мүмкін.
2. Hovq ішінде серверді қосып, SSH құпиясөзін енгізіңіз немесе жеке кілтті таңдаңыз. Саусақ ізін провайдердің басқару тақтасымен салыстырыңыз. SSH арқылы VPS ішіндегі `127.0.0.1:18777` мекенжайына бағыттауға рұқсат қажет. Орнатуды растаңыз және қажет болса sudo құпиясөзін енгізіңіз. Орнатылған агентке де қосылуға болады.
3. ЖИ параметрлерінде провайдерді, модельді және API кілтін көрсетіңіз. OpenRouter және UnoRouter модель каталогтарын қолданбада жүктеуге болады. Дереккөзді қосып, өңдеу профилін таңдап, жинауды бастаңыз.
4. Шығарылымды таспадан ашыңыз. Кестені жаңалықтар параметрлерінен, дайджест тілін ЖИ параметрлерінен таңдаңыз. Интерфейс пен дайджесттер жоғарыда көрсетілген барлық тілді қолдайды.

## Хабарландырулар және жаңарту

**Параметрлер → Интерфейс → Хабарландырулар** бөлімінде жаңа дайджест хабарландыруларын қосып, Android-та рұқсат беріңіз. Hovq VPS серверіне SSH немесе бапталған HTTPS арқылы тікелей қосылымды сақтайды. Бақылау кезінде Android дыбыссыз қызметтік хабарландыру көрсетеді. Дайджест дайын болғанда бөлек хабарландыру келеді. Байланыс үзілсе, Hovq қайта қосылып, жаңа шығарылымды тексереді.

Сертификаты бірдей Hovq 0.4.5–0.5.5 нұсқасының үстінен APK орнатуға болады. 0.4.4 және одан ескі нұсқалар таза орнатуды қажет етеді. Бұрын қосылған VPS серверіндегі агентті Hovq арқылы 0.1.18 нұсқасына жаңартыңыз. Мәтінді қолмен толықтыру режимінде де агент әртүрлі жазылған мақалалардың бір оқиға туралы екенін тексереді. Әр профильдің тақырыптық қайталауларды жою параметрі қолданыла береді.

## Бастапқы кодтан құрастыру

JDK 17 немесе 21, Android SDK 36 және Build Tools 36.0.0 қажет. SDK жолын `ANDROID_HOME` немесе `android/local.properties` арқылы көрсетіңіз.

```bash
cd android
./gradlew :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
```

Қолтаңбасы бар жинақ алу үшін мына орта айнымалыларын орнатыңыз

`HM_RELEASE_KEYSTORE`, `HM_RELEASE_KEY_ALIAS`, `HM_RELEASE_STORE_PASSWORD`, `HM_RELEASE_KEY_PASSWORD`
