# Visual test inputs

These files are test-only inputs for a repeatable 105-story issue. They are excluded from the released APK. Headlines and server state in visual tests are fixtures. The configuration comes from the pinned Horizon schema and its public built-in profiles.

The four JPEGs are resized NASA Image and Video Library photographs.

- earth.jpg — ISS Expedition 40, sunrise over the horizon: https://images.nasa.gov/details/iss040e033340
- as11-40-5875.jpg — Apollo 11 lunar surface: https://images.nasa.gov/details/as11-40-5875
- iss042e013697.jpg — Earth observation during Expedition 42: https://images.nasa.gov/details/iss042e013697
- iss036e030926.jpg — Earth observation during Expedition 36: https://images.nasa.gov/details/iss036e030926
