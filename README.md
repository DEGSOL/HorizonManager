# Hovq 0.4.5

Hovq управляет Horizon на VPS и открывает новостные дайджесты. Агент 0.1.11 поддерживает 11 языков дайджеста и настраиваемый предел в 2–30 слов для заголовков будущих выпусков. Hovq 0.4.5 подписан новым ключом. При переходе с предыдущих версий требуется чистая установка. Перед удалением прежней версии экспортируйте настройки телефона через «Настройки → Обслуживание → Резервные копии и перенос». Импортируйте копию после установки 0.4.5. Дайджесты на VPS останутся доступны для синхронизации.

В ленте заголовок «Лента» с датой выпуска открывает сведения о дайджесте, синхронизацию, полный текст и меню действий. Шапка и нижний бар синхронно скрываются при прокрутке. Поиск и фильтры открываются поверх ленты и сохраняют её положение. Скачанные обложки сохраняются на телефоне и доступны вместе с выпусками без интернета. Карточки раскрываются поверх асимметричной ленты. Три нижние кнопки открывают ленту, настройки и избранное. Краткие сообщения появляются вверху экрана. В «Настройки → Интерфейс» можно выбрать белый или чёрный фон значка. Журнал доступен в «Настройки → Обслуживание».

В стеклянной панели «Лента» показывает число непрочитанных загруженных карточек текущего дайджеста. Непрочитанные карточки выделены волнистым контуром, который меняет яркость в зависимости от фона. Счётчик обновляется при синхронизации и чтении новости, а при переходе в архив продолжает показывать состояние ленты.

Пункт «Настройки → Архив дайджестов» открывает прошлые выпуски. «Удалить с устройства» удаляет локальную копию выпуска и скрывает его после синхронизации. Копия на VPS и тексты новостей, сохранённых звездой, остаются доступными на своих местах. Веб-ссылки открываются внутри приложения во вкладке системного браузера или во встроенном WebView.

В «Настройки → Новости и источники» собраны интеграции, правила дайджеста, иллюстрации и расписание. Агент 0.1.4 умеет собирать изображения Telegram, RSS и обложки страниц. По желанию можно включить тематический поиск в Wikimedia Commons для новых выпусков. Выбор использует дополнительные запросы к настроенной модели AI. Обновление агента доступно в «Настройки → Обслуживание». Старые выпуски и агент 0.1.3 поддерживаются, приложение пытается получить обложку из исходной публикации.

В «Настройки → Обработка AI → Язык дайджеста» выбирается один язык для новых выпусков и статей. Агент 0.1.6 сохраняет его на VPS и использует при ручном запуске и по расписанию. В режиме «По запросу» заголовки и описания переводятся пакетами перед публикацией, а «Подробнее» обогащает статью только на языке открытого выпуска. Существующие языковые версии в архиве доступны как раньше. После установки APK обновите агент в «Настройки → Обслуживание».

Агент использует готовый русский или китайский текст, когда он уже есть, и сохраняет оригинал, если перевод недоступен. При синхронизации старые заглушки заменяются уцелевшим текстом из сохранённого выпуска. Приложение получает обложки через авторизованное подключение к VPS и показывает канал по метаданным Telegram-поста, даже когда новость ведёт на внешний сайт. Агент 0.1.8 повторяет некорректные ответы классификатора и переводит пропущенные карточки отдельными запросами.

## Первый запуск с телефона

1. Установите APK на Android 8.0 или новее. Понадобится ваш VPS с Ubuntu Server 24.04 LTS либо Debian 12, systemd, SSH и доступом к репозиториям ОС, GitHub и PyPI. Установщик проверяет архитектуру, минимум 432 МиБ RAM по MemTotal и 1,5 ГиБ свободного диска. Рабочее потребление зависит от выбранных источников и объёма обработки. Для длительной эксплуатации оставьте запас RAM и диска.
2. Введите данные SSH. Можно выбрать файл приватного ключа через системный проводник. При первом подключении сверьте отпечаток SSH с доверенным источником, например панелью провайдера VPS. SSH-сервер должен разрешать локальную переадресацию до `127.0.0.1:18777`.
3. Просмотрите отчёт и подтвердите установку. При необходимости укажите пароль sudo. Установка подготавливает недостающие пакеты и включает службу Horizon Manager. Телефон может отключиться после создания серверного задания. После возвращения приложение загрузит состояние по SSH.
4. В разделе «Настройки → Обработка AI» откройте «Модель AI». Укажите провайдера и точный идентификатор модели. Сохраните. Введите API-ключ в настройках AI и сохраните. Смена телефона и переустановка Android-клиента не стирают ключ в базе агента. «Проверить сохранённую модель» делает небольшой реальный запрос. Результат виден в истории заданий и журнале.
   Для OpenRouter и UnoRouter на том же экране введите ключ и нажмите «Подключить и загрузить модели». Выберите модель через поиск и сохраните настройки. При повторном открытии агент загружает каталог ключом из базы VPS. Android получает список моделей и имя сохранённого секрета. После переустановки Android-клиента выберите «Подключить существующий агент» в настройке VPS. Снова вводить AI-ключ при подключении к той же базе не требуется.
5. Откройте «Настройки → Источники → RSS / Atom», добавьте ленту с недавними публикациями, задайте название и URL, включите её и примените настройки. Выберите соответствующий профиль. Тест сохранённого источника позволяет проверить сбор без затрат на AI.
6. Нажмите «Запустить сбор». Следите за этапами в разделе «Настройки → Подключение и сервер → Управление». Когда Horizon сформирует дайджест, в «Ленте» появятся карточки и Markdown. Если свежих публикаций нет либо все отфильтрованы, интерфейс покажет фактический результат.
7. В разделе «Новости и источники → Расписание» выберите запуск вручную, по дням недели или через заданное число часов. Для ежедневной обработки выберите «Каждый день», время и город. Сохраните расписание. Экран покажет следующий запуск по данным VPS. Планировщик работает и при отключённом телефоне.

В профиле соединения HTTPS можно указать доверенный домен, на котором уже работает обратный прокси к агенту. По умолчанию API доступен внутри канала SSH. В «Настройки → Интерфейс → Уведомления» включите «Уведомления о новых дайджестах» и разрешите уведомления. При включении уведомлений Hovq автоматически пытается подключить установленный ntfy или уже выбранную службу UnifiedPush. Службу можно выбрать вручную в разделе уведомлений. По умолчанию агент принимает адреса доставки ntfy.sh. Для собственного сервера ntfy задайте `HM_PUSH_HOST` через systemd override агента и выберите тот же сервер в ntfy. Отдельный публичный адрес для Horizon Manager при этом не требуется.

При push телефон получает только подписанный идентификатор нового выпуска. Без подключённого push Android планирует сетевую проверку с интервалом 15 минут, а при активном push сверяет выпуски раз в шесть часов. Точное время фоновых проверок выбирает Android. После нажатия на уведомление приложение открывает ленту указанного VPS.

Новые выпуски формируются только на выбранном языке. Для старых выпусков без указанного языка генерации доступна операция «Перевести выпуск» в архиве. Она использует сохранённые материалы и текущего AI-провайдера.

### Данные и резервная копия

В «Настройки → Обслуживание → Резервные копии и перенос» доступны два типа зашифрованных файлов. Файл Horizon содержит настройки, профили, источники, секреты и расписание VPS. Файл Hovq содержит настройки телефона, сохранённые подключения с учётными данными, тему, значок и сортировку. При импорте Hovq записи с совпадающим идентификатором обновляются, остальные подключения остаются в списке. В копии не входят выпуски, журнал и облачные регистрации push.

## Сборка Android

Откройте папку `android` в Android Studio либо используйте Gradle Wrapper. Нужны полный JDK 17 или 21 и Android SDK с `platforms;android-36` и `build-tools;36.0.0`. SDK указывается через `ANDROID_HOME` или `android/local.properties`. Wrapper фиксирует Gradle 8.13 и SHA-256 официального архива.

```bash
cd android
./gradlew :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
```

Путь подписанного результата — `android/app/build/outputs/apk/release/app-release.apk`. Перед сборкой задайте `HM_RELEASE_KEYSTORE`, `HM_RELEASE_KEY_ALIAS`, `HM_RELEASE_STORE_PASSWORD` и `HM_RELEASE_KEY_PASSWORD` в своём защищённом окружении. Сборка без этих переменных выдаёт неподписанный APK. Для обновления поверх установленной версии нужен тот же сертификат. В среде с ограниченной памятью можно добавить `--max-workers=1 -Pkotlin.compiler.execution.strategy=in-process`.
