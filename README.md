# Hovq 0.6.7

**Русский** · [English](docs/readme/README.en.md) · [Deutsch](docs/readme/README.de.md) · [Français](docs/readme/README.fr.md) · [Italiano](docs/readme/README.it.md) · [Español](docs/readme/README.es.md) · [日本語](docs/readme/README.ja.md) · [한국어](docs/readme/README.ko.md) · [简体中文](docs/readme/README.zh.md) · [Қазақша](docs/readme/README.kk.md) · [Татарча](docs/readme/README.tt.md)

Hovq — Android-приложение для установки и управления [Horizon](https://github.com/Thysrael/Horizon) на собственном VPS и чтения новостных дайджестов. На сервере Horizon собирает материалы, убирает повторы и использует выбранную модель ИИ для оценки, перевода и подготовки выпуска.

[Скачать подписанный APK и посмотреть изменения](https://github.com/DEGSOL/HorizonManager/releases/latest)

## Возможности

- Источники RSS, Telegram, Reddit и Hacker News, профили оценки, обложки и обогащение по запросу.
- Запуск вручную, по дням недели или через равные интервалы с заданного времени. Расписание выполняется на VPS.
- Лента с поиском, фильтрами и непрочитанными статьями, избранное, архив и скачанные выпуски для чтения офлайн.
- Журнал операций и зашифрованные резервные копии настроек телефона и сервера.

## Установка и первый выпуск

**Для установки достаточно своего VPS с Ubuntu Server 24.04 LTS или Debian 12 и доступом по SSH.** Подключитесь к нему из Hovq, подтвердите установку, и приложение само установит Horizon, агент и необходимые зависимости.

1. Установите APK на Android 8.0 или новее. Подготовьте VPS с Ubuntu Server 24.04 LTS или Debian 12, systemd, SSH и доступом к репозиториям ОС, GitHub и PyPI. Установщик проверяет архитектуру, минимум 432 МиБ RAM и 1,5 ГиБ свободного места. Сбор и обработка могут потребовать больше ресурсов.
2. Добавьте сервер в Hovq, введите пароль SSH или выберите приватный ключ и сверьте отпечаток с панелью провайдера. SSH должен разрешать переадресацию на `127.0.0.1:18777` на VPS. Подтвердите установку и при необходимости введите пароль sudo. Для существующего агента доступно подключение без повторной установки.
3. В настройках обработки ИИ укажите провайдера, модель и API-ключ. Для OpenRouter и UnoRouter каталог моделей можно загрузить из приложения. Добавьте источник, выберите профиль обработки и запустите сбор.
4. Откройте выпуск в «Ленте». В разделе «Настройки → Новости и источники» можно выбрать расписание, язык и доставку выпусков. Интерфейс и дайджесты поддерживают все языки, перечисленные выше.

## Вход через ChatGPT

Откройте **Настройки → Обработка AI → Модель AI**, выберите «ChatGPT по подписке» и нажмите «Войти через ChatGPT». После разрешения в браузере вернитесь в Hovq, выберите доступную модель. Настройки сохраняются при выборе модели. Кнопка «Проверить сохранённую модель» выполняет запрос с VPS и показывает ответ или причину ошибки. Вход требует аккаунт с доступом к использованию лимита подписки. Сессия ChatGPT хранится на выбранном VPS.

## Уведомления и обновление

Включите «Уведомления о новых дайджестах» в **Настройки → Интерфейс → Уведомления** и разрешите их в Android. Hovq держит прямое подключение к VPS по SSH или по настроенному HTTPS. Пока работает мониторинг, Android показывает тихое служебное уведомление. О готовом выпуске приходит отдельное уведомление. При обрыве связи Hovq переподключается и сверяет, вышел ли новый выпуск.

APK можно установить поверх Hovq 0.4.5–0.6.6 с тем же сертификатом. Для версий 0.4.4 и старше нужна чистая установка. Каждая сборка Hovq с проверкой совместимости устанавливает собственную версию агента. Для 0.6.7 это агент 0.1.23. Если на VPS обнаружена более новая версия, приложение предложит откат. Перед откатом установщик сохранит резервную копию базы агента. Если установка завершится с ошибкой, он восстановит предыдущую версию и базу. Ранее выпущенные APK сохраняют встроенную в них логику.

## Формирование текста новостей

В **Настройки → Обработка AI → Профили обработки** откройте профиль и раздел **Формирование текста новости**. Выберите краткий текст из одного предложения или подробную новость. Для подробной новости можно отредактировать многострочную инструкцию и восстановить её стандартное значение. Настройки применяются при первичной оценке, в том числе при выключенном автообогащении.

- Новые профили получают лимиты Hovq. Модель видит до 6000 символов исходной публикации при оценке и до 8000 при обогащении. Существующие профили сохраняют свои значения. Кнопки «Базовые Horizon» и «Сбросить к Hovq» устанавливают лимиты соответствующего режима и выборку с начала.
- Если публикация длиннее лимита, можно передать модели начало либо отрывки из начала, середины и конца. Оба метода работают и при ручном обогащении через «Подробнее».
- В **Настройки → Интерфейс → Поведение ленты** выберите подготовленную новость или вид карточки «Как раньше». Переключатель «Показывать обоснование оценки» выводит объяснение отдельным блоком. По умолчанию он выключен.

Профили и настройки карточек хранятся на выбранном VPS и входят в серверную резервную копию. Новые параметры формирования текста действуют для следующих дайджестов.

## Сборка из исходников

Нужны JDK 17 или 21, Android SDK 36 и Build Tools 36.0.0. Укажите SDK через `ANDROID_HOME` или `android/local.properties`.

```bash
cd android
./gradlew :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
```

Для подписанной сборки передайте переменные

`HM_RELEASE_KEYSTORE`, `HM_RELEASE_KEY_ALIAS`, `HM_RELEASE_STORE_PASSWORD`, `HM_RELEASE_KEY_PASSWORD`
